# SQL-injection

An educational Python utility designed to explore web security vulnerabilities, specifically SQL injection (SQLi) mechanics and defensive techniques.

---

## Features

- **Vulnerability Demonstration:** Simulates basic SQL injection vectors against controlled test endpoints.
- **Payload Testing:** Demonstrates basic payload construction for authentication bypass and data extraction research.
- **Security Awareness:** Highlights proper parameterization strategies to prevent SQLi risks in web applications.

## Tech Stack

- **Language:** Python 3.x
- **Dependencies:** `requests`
